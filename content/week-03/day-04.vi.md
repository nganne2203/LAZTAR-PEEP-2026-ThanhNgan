# Báo cáo ngày 04

## 1. Mục tiêu hôm nay

Hôm nay em tập trung cải thiện giao diện frontend, refactor source code và rà soát cách tổ chức package trong dự án. Bên cạnh đó, em thực hiện code review và đề xuất chuẩn hóa cách trao đổi request/response giữa frontend và backend.

## 2. Cải thiện UI frontend

Em chỉnh sửa giao diện frontend để các màn hình rõ ràng, nhất quán và thuận tiện hơn trong quá trình thao tác. Các thay đổi tập trung vào cách bố trí và trình bày thông tin, tạo nền tảng tốt hơn cho việc tiếp tục hoàn thiện các luồng nghiệp vụ.

## 3. Refactor source code và chuẩn hóa package

Em rà soát, refactor một số phần trong source code để cấu trúc dễ theo dõi và bảo trì hơn. Đồng thời, em xem xét lại cách tổ chức package nhằm thống nhất cách phân chia và sử dụng các thành phần trong dự án, hạn chế sự thiếu nhất quán khi bổ sung chức năng.

## 4. Code review và đề xuất chuẩn hóa API

Trong quá trình review, em đề xuất thống nhất quy ước đặt tên theo camelCase cho dữ liệu request và response giữa frontend và backend. Việc dùng chung một quy ước giúp giảm các bước chuyển đổi dữ liệu và hạn chế nhầm lẫn khi tích hợp.

Em cũng đề xuất sử dụng package validation phù hợp thay cho việc kiểm tra dữ liệu thủ công. Cách này giúp quy tắc validation rõ ràng, nhất quán và dễ tái sử dụng hơn. Đây là các đề xuất cần được thống nhất giữa frontend và backend trước khi áp dụng đồng bộ.

## 5. Tổng kết và bước tiếp theo

Hôm nay em đã tập trung cải thiện UI, refactor source code, rà soát cách tổ chức package và đưa ra một số kiến nghị qua code review. Tiếp theo, em sẽ tiếp tục hoàn thiện các phần đã chỉnh sửa và phối hợp thống nhất quy ước request/response cùng cách validation với phía backend.
